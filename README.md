# Project Overview

CyberThana is a citizen-facing web application designed to simplify the process of reporting cybercrime incidents, especially in rural and semi-urban areas. The platform enables users to submit cybercrime reports through a simple interface and receive a tracking ID for future reference.

This project is developed as part of the Civora Nexus Internship Program and focuses on frontend development, backend API design, and proper documentation rather than full production implementation.

CyberThana - Rural Cybercrime Reporting Portal 
Module: Cybercrime Reporting ( Citizen Side )
This module focuses on guided cybercrime reporting forms,evidence upload, and tracking ID generation.

Tech Stack :
-Frontend: HTML/CSS
-Backend: Python
-Database: Postgresql/ MongoDB
