# Feature Scope & Limitations

# Implemented Features
- Citizen can submit a cybercrime report
- Frontend form with basic validation
- Backend mock API for report submission
- Tracking ID generation for reports

# Planned Features
- Report status tracking
- Admin review dashboard
- Notification system

# Limitations
- No real database integration
- No authentication or authorization
- APIs return mock data
- Project is for learning and demonstration purposes only
